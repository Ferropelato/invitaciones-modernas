# Invitaciones Modernas — Sellomail

Invitaciones digitales para todo tipo de evento. Cada template incluye:

- ⏱ Countdown en tiempo real
- 📍 Dirección + link a Google Maps
- 📸 Álbum compartido en Google Drive
- 📩 Formulario de RSVP
- 🎨 Selector de paleta de colores (4 opciones)
- ✨ Animaciones al hacer scroll
